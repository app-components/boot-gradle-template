# Customize this template into a new project

The presence of this one-time bootstrap todo marks the repository as being in template state: it
still carries the boot-gradle-template identity, sample applications, and template-describing
documentation. Execute it only when the user explicitly asks to customize the current repository;
ordinary maintenance requests do not activate it. Follow the [customization plan](plan.md), and
keep this note until the plan is complete so interrupted customization can resume from checked-in
context.
